# The Battery's Last Text to Its Charger

A one-line entry for the make.fun competition "The Battery's Last Text to Its Charger".

The battery dimmed itself, killed every app it loved, and clung to 1% all day
waiting for its charger — which was in the same pocket the whole time,
unplugged. The punchline lands on the double meaning of "never made contact":
no electrical contact, and no effort in the relationship either.

## Run

```sh
python3 main.py
```

Writes the single-line entry to `/output/entry.txt` (set `OUTPUT_DIR` to
redirect it for local testing). The line is plain text, one line, well under
the competition's 200-character limit.
